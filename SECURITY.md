# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, please email security concerns to the repository maintainers directly or use [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

### What to expect

- Acknowledgment within 48 hours
- An assessment of the vulnerability within 1 week
- A fix or mitigation plan within 30 days for confirmed vulnerabilities

### Scope

This policy covers the `hiivmind-pulse-gh` Claude Code plugin, including:
- Skills and command definitions
- Pattern and reference library files
- Configuration templates
- Workflow automation files
